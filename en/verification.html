Verification scope

The records below belong to the September 12 source snapshot. The two compilers and KUROSAKI CLI were built from the collected sources. KOKURA and SARAKURA used local executables fingerprinted in the inventory. These checks do not cover all features, peripherals or physical hardware.

Each entry records compilation, a 120-frame emulator run and its screenshot. Pixel comparisons are separate evidence. Exit code zero alone does not prove correct input, sound or game behavior. Publication builds and workspace tests performed later are documented in publication checks; translating the manuals did not rerun every historical observation.
