Rust 1.85 was also tested. PUBLIC_DISTRIBUTION.json records the installed binary hashes and validation provenance. The public GitHub Actions workflows rebuild and test this source independently.

Frozen reference outputs test ROM bytes, diagnostics and helper formats. Earlier C# emulator evidence remains historical evidence with its original source fingerprints. It does not automatically prove every Rust API, real hardware or complete FDS BIOS/game startup. The unavailable original PNG conversion script was reconstructed from its specification; byte parity with that missing script cannot be claimed.

Local library changes and verification, 2026-10-03

Sources from C:/kitaqgb_project/lib were compared with public revision 2de7f4b. Timestamps alone do not establish which version is newer. The local version has additions; the public version has other additions and fixes. This section describes the saved local sources, separately from the existing public API evidence.

physics2d.c retains the contact API and adds cached contact and speed-limit implementations under KQ2D_CACHE_SURFACE. Reserve ROM bank 13 when enabling it. Defining KQ2D_EXTERNAL_SCALE_Q8, KQ2D_EXTERNAL_REST_COMPONENT or KQ2D_EXTERNAL_SURFACE requires the caller to supply the corresponding implementation. The 8,872 cases below exercised the default path without these definitions.

KQ3D_BODY_SPHERE=0x04 selects sphere–box contacts. The sphere radius is half_x. kq3d_overlap_sphere_aabb(sphere, box) includes tangency and returns 0 for NULL pointers or a nonpositive radius. There is no dedicated sphere–sphere solver. Keep coordinate differences, products and squared-distance sums within their 16-bit ranges.

An active body with KQ3D_BODY_KINEMATIC=0x02 updates X/Y velocity and position in kq3d_step even with zero inverse mass. Its Z position and velocity remain unchanged. Contacts do not displace a body with zero inverse mass. kq3d_integrate_body still skips static bodies. Neither break_speed nor KQ3D_BODY_BROKEN causes automatic destruction.

Local bank_switch writes kq_bank_current and address 0x2000. Unlike the public __bankswitch path, it does not update the compiler's bank tracking state. Switch from the fixed bank; use __bankswitch when compiler bank restoration state must also be maintained.

Local cgb_bg_color/cgb_obj_color, including the single-color RGB wrappers, do not enable palette index auto-increment. CGB execution confirmed that the low byte of 0x1234 is overwritten with 0x12. Use the public fix or a colors array API for single-color writes. DMG performs no write.

Local metasprite_draw extends the used count to first_id+count only on completion. An early return at the 40-sprite limit does not update it. With first_id=39 and count=2, the return value was 1, slot 39 was active, and the used count was 0. The public implementation updates the count as each slot is processed.

The local version provides vram_get_queue_used and vram_get_queue_free, but lacks public vram_get_queue_capacity. Use VRAM_QUEUE_MAX for capacity; its default is 32. One queued command produced used=1 and free=31.

wire3d_dmg.h declares DrawRect2D only for the 96-line profile. DrawBoxEdges2D is declared for both profiles; DrawIndexedEdges only for the 120-line profile. Select one source matching the profile. Rendering by these functions was not reverified in this run. No implementation of DrawRect2D or DrawBoxEdges2D was found in the saved lib sources. These are declarations only; calling them requires a separate implementation.

Local audio_vblank lacks the public AudioVBlank_QueueReset/QueueRefill/QueuePlay APIs and audio_vblank_queue.inc. ZX0 is also public-only. These are public additions and are excluded from claims about verified local features.

Physics boundaries: 19 cases in both DMG and CGB, all 38 runs passed. Separate 3D extension and sprite/VRAM/palette reproduction cases matched expected values in both modes. Palette and sprite results reproduce defects; they are not confirmations of correct operation.

Display the supplied character set gb_font

Purpose: See which letters, digits and punctuation marks the supplied original font contains and how to draw them.

How it works: m_init prepares the display and font. m_text draws each row; m_put draws the double quote using character code 34.

Controls and expected result: Look for 26 uppercase letters, 26 lowercase letters, 10 digits and 30 punctuation marks. Check that every glyph is legible. No input is required.
