原生編譯器驗證

Windows、Linux、macOS ARM 和 macOS Intel 的原生建置及執行驗證均成功。KITAQGB 在每個環境通過 48 項測試與 395 項輔助工具檢查；KITAQFC 通過 55 項測試與 401 項檢查，也驗證了 Rust 1.85。PUBLIC_DISTRIBUTION.json 記錄已配置程式的雜湊與驗證來源。公開 GitHub Actions 會獨立建置及驗證這些原始碼。

保存的參考輸出用於檢查 ROM 位元組、診斷與輔助工具格式。先前的 C# 模擬器驗證保留為對應原始碼指紋的歷史紀錄，並不自動證明所有 Rust API、實體硬體或完整的 FDS BIOS 遊戲啟動。原始 PNG 轉換腳本無法取得，因此依規格重新實作，不能宣稱與原腳本位元組一致。

從這裡開始

KITAQGB 起初是 Zachtronics 相關 NES C 編譯器 NORCAL 的分支專案。在這個基礎上，專案針對 Game Boy 與 Game Boy Color 的處理器、記憶體、影像、音訊及 ROM 分頁機制加以擴充，形成一套 C 語言開發工具。我們保留原作者 Keith Holman 的著作權聲明，也感謝原專案的貢獻。

NORCAL的名稱源自北加利福尼亞（Northern California）。受到這種以地名命名的方式啟發，作者以自己出生並成長的北九州市為基礎，將專案命名為KITAQGB。KITAQ + GB把日本福岡縣北九州市的暱稱北九（キタキュー，Kitakyū）與Game Boy結合起來。KITAQ讀作日語「キタキュー」；英語發音提示為 kee-tah-KYOO，音標為 /ˌkiːtɑːˈkjuː/。最後的Q與英語字母Q同音。KITAQGB中的G和B分別按照字母名稱發音，整個名稱讀作 kee-tah-KYOO jee bee。

KITAQGB這個名稱有兩層意義。Kernel-Informed Toolchain for AI-Quality Game Boy Development表達了工具鏈應理解目標硬體，同時支援程式設計者與生成式AI的目標。

另一層意義是 Kids' Imagination Transformed into Actual Quests in Game Boy Forests，意指「把孩子的想像，化為Game Boy森林裡真實冒險的工具」。這寄託了一份創作心願：讓小小的點子、塗鴉及借助AI製作的原型，成為真正可以遊玩的冒險。

NORCAL 的開發與 NES 版 HACK*MATCH 有關。背景可參閱原作者的 NORCAL 介紹與 NES 版 HACK*MATCH 介紹。

如何使用這套手冊

這套手冊採用早期電腦手冊的方式：先輸入一個小程式，完成編譯並看到執行結果，再逐步認識機器的運作。剛開始不必記住所有術語。

  1. GB 開發從第 1 卷的第一個程式開始；FC 開發則從第 4 卷開始。
  2. 透過第 2 卷或第 5 卷加入輸入、圖像和聲音。
  3. 使用 KOKURA 或 KUROSAKI 觀察執行，再由 SARAKURA 整理診斷結果。
  4. 已知函式名稱時，可直接使用卷內搜尋或 API 辭典。

語言語法、編譯器內建函式、函式庫函式和命令列操作是不同類型的參考項目。編譯器分卷另附 CPU 指令索引。GB 與 FC 的函式即使同名，參數和行為也不一定相同。

範例使用的字形

範例使用作者自行製作的 ascii.c，包含 26 個大寫字母、10 個數字、26 個小寫字母和 30 個符號，共 92 個字形。完整字形請見圖塊總覽。空格使用空白圖塊；字型未包含反斜線和直線符號，這兩者會顯示為空白。gb_font.c 與 fc_font.c 可顯示全部字形。

版本與驗證範圍

本手冊以 2026年9月14日的原始碼為依據。參考清單記錄了原始碼與執行檔的雜湊值。各項測試的輸入、條件與驗證範圍請參閱驗證紀錄。

建置成功表示已產生 ROM；執行檢查表示模擬器前進了指定的影格數。像素比對、輸入行為和音訊檢查分別記錄。這些檢查並不保證所有周邊裝置或實體主機的相容性，日誌中的警告也予以保留。

準備工作目錄

範例命令以 Windows PowerShell 為準。C 檔案請儲存為 UTF-8 文字。「目前目錄」就是執行命令的位置。含空格的路徑需加引號；必要時使用 & "路徑" 呼叫執行檔。跨工具範例假設各工具的儲存庫與遊戲專案位於同一個上層目錄，命令也從該上層目錄執行。

powershell
# リポジトリのルートで実行します。
New-Item -ItemType Directory -Force out | Out-Null
.\kitaqgb\kitaqgb.exe --help
.\kitaqfc\kitaqfc.exe --help

請將 game.c、game.gb 和 game.nes 換成自己的檔名。<ROM> 這類角括號內容表示待填入的參數，輸入時不要保留括號。命令通常以單行呈現。Bash 的反斜線續行方式不是 PowerShell 語法。

閱讀與列印 HTML

開啟下載目錄中的 index.html 即可離線閱讀。樣式、搜尋、範例與驗證圖片皆使用本機檔案，不依賴外部 CDN。請保留整個目錄結構，不要只複製單一 HTML 檔案。列印按鈕會使用隱藏側欄的列印版面。

原始碼摘錄和實際工具輸出維持原文，方便與檔案或命令結果直接核對。
