## HTML 手冊

[繁體中文](https://bartaro.github.io/kitaq-docs/zh-TW/index.html)

七冊手冊收錄各 API 的個別說明與完整範例程式。繁體中文版可從 `zh-TW/index.html` 開啟。各卷的語言選單可切換至其他語言；範例說明列出已確認的行為與條件。

原始碼節錄保留原文，並在範例說明旁附上模擬器擷取的執行畫面。HTML 支援離線閱讀、卷內搜尋、程式碼複製與列印。

| 檔案／直接開啟 | 內容 |
|---|---|
| [kitaqgb.html](https://bartaro.github.io/kitaq-docs/zh-TW/kitaqgb.html) | KITAQGB 語法、編譯器內建函式與建置 |
| [gb-library.html](https://bartaro.github.io/kitaq-docs/zh-TW/gb-library.html) | KITAQGB 程式庫 |
| [kokura.html](https://bartaro.github.io/kitaq-docs/zh-TW/kokura.html) | KOKURA 執行、輸入、觀察與記錄 |

| [fc-library.html](https://bartaro.github.io/kitaq-docs/zh-TW/fc-library.html) | KITAQFC 程式庫 |
| [kurosaki.html](https://bartaro.github.io/kitaq-docs/zh-TW/kurosaki.html) | KUROSAKI 執行、儲存與分析 |
