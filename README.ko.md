## HTML 매뉴얼

[한국어](https://bartaro.github.io/kitaq-docs/ko/index.html)

7권의 매뉴얼에 API별 설명과 완전한 샘플 프로그램을 수록했습니다. 한국어판은 `ko/index.html`에서 열 수 있습니다. 각 권의 언어 메뉴로 다른 언어판을 선택할 수 있으며, 예제 설명에는 확인 대상 동작과 조건이 나와 있습니다.

원본 소스에서 발췌한 코드는 그대로 유지하고, 에뮬레이터에서 캡처한 화면을 예제 설명 옆에 배치했습니다. HTML은 오프라인 열람, 권 내 검색, 코드 복사, 인쇄를 지원합니다.

| 파일 / 바로 열기 | 내용 |
|---|---|
| [kitaqgb.html](https://bartaro.github.io/kitaq-docs/ko/kitaqgb.html) | KITAQGB 문법, 컴파일러 내장 함수, 빌드 |
| [gb-library.html](https://bartaro.github.io/kitaq-docs/ko/gb-library.html) | KITAQGB 라이브러리 |
| [kokura.html](https://bartaro.github.io/kitaq-docs/ko/kokura.html) | KOKURA 실행, 입력, 관찰, 기록 |
| [kitaqfc.html](https://bartaro.github.io/kitaq-docs/ko/kitaqfc.html) | KITAQFC 문법, 컴파일러 내장 함수, 빌드 |
| [fc-library.html](https://bartaro.github.io/kitaq-docs/ko/fc-library.html) | KITAQFC 라이브러리 |
| [kurosaki.html](https://bartaro.github.io/kitaq-docs/ko/kurosaki.html) | KUROSAKI 실행, 저장, 분석 |
| [sarakura.html](https://bartaro.github.io/kitaq-docs/ko/sarakura.html) | SARAKURA 진단과 재검증 |
| [verification.html](https://bartaro.github.io/kitaq-docs/ko/verification.html) | 예제 실행 화면 |
