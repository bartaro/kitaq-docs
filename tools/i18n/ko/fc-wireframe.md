`wire3d.c`는 직접 만든 3D 모델을 어두운 배경 위에 청록색 선으로 그립니다. 정수 회전 연산, 역수 표를 이용한 원근 투영, CPU 측 픽셀 버퍼, CHR RAM 패턴 테이블 두 개를 사용합니다. 상용 게임의 코드·모델·그래픽 데이터는 포함하지 않습니다. 소스는 DAISUKE OBA가 MIT 라이선스로 제공합니다.

`wire3d.c`를 포함하기 전에 뷰포트 크기를 64×48, 96×64, 128×96 중에서 선택하세요. `WIRE3D_FC_WIDTH`와 `WIRE3D_FC_HEIGHT`를 **둘 다** 정의합니다. 기본값은 64×48입니다. 뷰포트는 256×240 배경의 중앙에 배치됩니다. 크기가 커지면 사용하는 타일 수와 그리는 선의 길이가 늘어나므로, 실제 장면의 처리 시간을 측정하여 선택하세요.

ROM에는 **쓰기 가능한 CHR RAM 8 KiB**와 `$6800–$70BF` 영역을 포함하는 카트리지 PRG RAM이 필요합니다. 렌더러는 패턴 테이블 두 개, 네임테이블 0, 스크롤, 배경 팔레트를 전용으로 사용하며 제로 페이지 `$00–$0A`도 예약합니다. 다른 용도로 이 영역을 겹쳐 사용하거나 그리는 동안 매퍼 매핑을 바꾸지 마세요. `--nes-chr-ram`은 CHR ROM 대신 RAM을 선택합니다. `--nes-chr` 또는 `--chr-rom`으로 그래픽 파일을 지정하는 옵션과 함께 사용할 수 없으며, CNROM 구성에서는 허용되지 않습니다.

렌더러는 재진입을 지원하지 않습니다. 초기화 시 NMI를 비활성화하고 설정을 마친 뒤 배경을 켭니다. 그리기와 업로드는 호출한 처리 흐름에서 실행됩니다. 동시에 PPU에 쓰는 다른 처리나 렌더러의 작업용 메모리를 변경하는 인터럽트 핸들러를 실행하지 마세요. 한 번의 업로드가 여러 화면 프레임에 걸칠 수 있습니다. 비동기 게임 루프나 오디오 갱신 스케줄러는 제공하지 않습니다.

| 함수 | 용도와 호출 조건 |
|---|---|
| `Wire3DFC_Init()` | CHR 테이블 두 개와 CPU 측 그리기 버퍼를 지우고 중앙에 배치할 타일 맵을 구성합니다. 어두운 배경에 청록색을 지정한 뒤 NMI가 비활성화된 상태로 배경을 켭니다. 다른 프레임 작업보다 먼저 호출하세요. |
| `Wire3DFC_BeginFrame()` | 직전 그리기에 사용한 CPU 측 타일을 지웁니다. 표시 중인 이미지는 `EndFrame`이 버퍼를 전환할 때까지 유지됩니다. 완성할 이미지를 구성하기 전에 한 번 호출하세요. |
| `Wire3DFC_DrawLine2D(ax,ay,bx,by)` | 양 끝점을 포함하는 선분을 CPU 버퍼에 그립니다. 끝점은 −512…511 범위의 부호 있는 좌표입니다. 뷰포트 밖의 픽셀은 잘라내며, 경계 상자 전체가 밖에 있는 선분은 제외합니다. 영역 안의 선은 6502 레지스터를 활용하는 Bresenham 루프로 그립니다. |
| `Wire3DFC_RotatePoint(x,y,z,rx,ry,rz)` | 서로 다른 쓰기 가능한 `s16` 성분 세 개를 Y, X, Z축 순서로 회전하여 갱신합니다. 각도는 한 바퀴를 32단계로 나타내며 순환합니다. 시작 시 각 성분을 −63…63 범위에 두세요. Q6 축소 시 소수 부분은 0 방향으로 버립니다. 성분 포인터가 하나라도 NULL이면 아무것도 변경하지 않습니다. |
| `Wire3DFC_ProjectPoint(x,y,z,sx,sy)` | 카메라 좌표의 점을 화면 좌표로 변환합니다. X/Y는 −127…127, 깊이는 32…255여야 합니다. 성공하면 1을 반환하고, 화면 영역으로 잘라내기 전의 부호 있는 좌표를 출력합니다. 좌표가 유효하지 않거나 출력 포인터가 NULL이면 출력을 변경하지 않고 0을 반환합니다. X의 양의 방향은 오른쪽, Y의 양의 방향은 위쪽입니다. |
| `Wire3DFC_DrawLine3D(ax,ay,az,bx,by,bz)` | 양 끝점을 투영한 뒤 화면에 선분을 그립니다. 한 끝점이라도 투영 범위를 벗어나면 변 전체를 생략합니다. 변과 근평면·원평면의 교점을 구해 자르는 처리는 하지 않습니다. |
| `Wire3DFC_DrawModel(vertices,count,edges,edge_count,x,y,z,rx,ry,rz)` | 처음 24개까지의 정점을 각각 한 번씩 변환·투영하여 결과를 저장한 뒤, 인덱스로 지정한 변을 그립니다. 정점은 `s8` 성분 세 개, 변은 `u8` 정점 인덱스 두 개로 구성됩니다. NULL 배열, 유효하지 않은 인덱스, 투영에서 제외된 끝점은 건너뜁니다. 평행이동 후의 합을 `s16` 범위에 유지하세요. 유효한 변은 모두 그리며, 이 API는 숨은 면을 제거하지 않습니다. |
| `Wire3DFC_EndFrame()` | 준비한 이미지 또는 비표시 CHR 버퍼의 이전 내용에 사용된 타일을 업로드합니다. 지워야 하는 타일도 포함됩니다. VBlank 한 번에 최대 16타일을 전송하고 스크롤을 복원한 뒤, 새로운 VBlank에서 완성된 이미지를 표시합니다. 완료될 때까지 반환하지 않습니다. |

`EndFrame` 실행 후 `wire3d_uploaded_tiles`는 업로드한 타일 수를 나타내고, `wire3d_transfer_frames`는 업로드 배치 수에 마지막 버퍼 전환 대기를 더한 값을 나타냅니다. 후자는 **전체 렌더링 소요 시간이 아닙니다**. 좌표 변환, 래스터화, CPU 측 상태 관리에도 시간이 걸립니다. 원근 투영에는 양자화된 역수 표를 사용하며, 폭 128픽셀에서 가장 가까운 깊이의 배율 값은 256에서 255로 제한됩니다.

HTML 설명서의 정육면체 예제는 정점 공유, 회전, 투영, 인덱스로 지정한 변 12개, 완성된 이미지의 표시 방법을 보여 줍니다. 검증 이미지는 Y축을 중심으로 회전한 정육면체입니다. 12개의 변이 모두 연결되어 있어야 하며, 이전 이미지의 선이 남아 있으면 안 됩니다.
