## 이 설명서를 시작하며
KITAQGB는 Zachtronics와 관련된 NES용 C 컴파일러 **NORCAL에서 출발한 포크**입니다. 이를 바탕으로 Game Boy와 Game Boy Color의 CPU, 메모리, 영상, 음향, ROM 뱅크 구조에 맞는 C 계열 개발 도구를 만들었습니다. 원작자인 Keith Holman의 저작권 표시를 유지하며, 원 프로젝트에 감사를 표합니다.

{{ORIGIN}}

NORCAL은 NES판 HACK*MATCH와 관련하여 개발되었습니다. 배경은 원작자의 [NORCAL 소개](https://keithholman.net/nes-compiler.html)와 [NES판 HACK*MATCH 소개](https://trashworldnews.com/hack-match/)에서 확인할 수 있습니다.

## 읽는 순서
옛 컴퓨터 설명서처럼, 직접 입력하고 빌드하여 실행해 볼 수 있는 짧은 프로그램부터 시작합니다. 처음부터 모든 용어를 외울 필요는 없습니다. 화면에 결과를 띄운 뒤 그 원리를 하나씩 익혀 보세요.

1. GB 개발은 제1권, FC 개발은 제4권의 첫 프로그램부터 시작합니다.
2. 제2권과 제5권에서 입력, 그래픽, 소리를 추가하는 방법을 살펴봅니다.
3. KOKURA 또는 KUROSAKI로 실행을 관찰하고, SARAKURA로 진단 결과를 정리합니다.
4. 함수 이름을 알고 있다면 해당 권의 검색 기능이나 API 사전을 이용합니다.

언어 문법, 컴파일러 내장 함수, 라이브러리 함수, 명령줄 명령은 서로 다른 참고 항목입니다. 컴파일러 편에는 CPU 명령어 색인도 있습니다. GB와 FC에서 이름이 같더라도 인수나 동작까지 같다고 가정하지 마세요.

## 전체 구성
| 설명서 | 입력 | 출력 또는 용도 |
| --- | --- | --- |
| KITAQGB | C 소스와 리소스 | GB/CGB ROM, 맵 파일, 빌드 정보 |
| KITAQGB 라이브러리 | 게임 코드의 함수 호출 | 그래픽, 음향, 입력, 통신, 게임 구성 기능 |
| KOKURA | GB/CGB ROM | 실행, 화면, 소리, 상태, 관찰 기록 |
| KITAQFC | C 소스와 CHR 리소스 | NES/FDS 출력과 빌드 정보 |
| KITAQFC 라이브러리 | 게임 코드의 함수 호출 | NES 그래픽, 음향, 주변기기 기능 |
| KUROSAKI | NES/FDS 이미지 | 실행, 기록, 분석 |
| SARAKURA | 빌드 정보와 진단 이벤트 | 보고서, 수정 계획, 재시험 계획 |

## 예제에 사용하는 글꼴
영문 대문자 26자, 숫자 10자, 소문자 26자, 기호 30자는 저자가 제공한 [ascii.c](samples/assets/ascii.c)에서 가져왔습니다. 새로운 글자 모양을 덧붙이지 않았으며, 원래의 92개 글리프를 그대로 보존합니다. [변환 대응표](verification/font_conversion.json)와 [타일 목록 이미지](verification/font_source_atlas.png)를 참고하세요. 공백에는 빈 타일을 사용합니다. 원본에 없는 역슬래시와 세로 막대는 공백으로 표시됩니다. `gb_font.c`와 `fc_font.c`를 실행하면 제공된 모든 글리프를 볼 수 있습니다.

## 판본과 검증 범위
이 판은 **2026년 9월 14일의 로컬 소스 스냅샷**을 기준으로 합니다. 여기서 ‘최신’은 이 스냅샷을 가리키며, 이후 GitHub의 변경 사항을 자동으로 반영한다는 뜻은 아닙니다. 소스와 실행 파일의 식별 정보는 참조 목록에 기록했습니다. 과거 README에 적힌 지원·검증 주장을 현재의 보증으로 그대로 받아들이지는 않습니다.

빌드 성공은 ROM이 생성되었다는 뜻입니다. 실행 검사는 지정한 프레임만큼 에뮬레이터가 진행했음을 뜻합니다. 픽셀 비교, 입력 동작, 소리 검사는 별도의 기록으로 구분합니다. 모든 주변기기나 실기와의 호환성을 보장하는 검사는 아니며, 경고도 로그에 남겨 두었습니다.

현재 공개 소스에는 KOKURA-GUI, KUROSAKI-GUI, PLITA가 포함되지 않습니다. 공개된 코어, CLI, 연동 API를 이용하세요.

## 작업 폴더 준비
예제 명령은 **Windows PowerShell**을 기준으로 합니다. C 파일은 UTF-8 텍스트로 저장하세요. 현재 폴더는 명령을 실행하는 위치입니다. 공백이 있는 경로는 따옴표로 감싸고, 필요하면 `& "경로"` 형태로 실행 파일을 호출합니다. [GitHub 배치 안내](../GITHUB_SETUP.md)에 따라 각 저장소를 같은 상위 폴더 아래에 나란히 복제하고, 여러 프로젝트를 함께 쓰는 명령은 그 상위 폴더에서 실행하세요.

{{CODE:0}}

`game.c`, `game.gb`, `game.nes`는 자신의 파일 이름으로 바꾸세요. `<ROM>`처럼 꺾쇠괄호로 표시된 부분은 대체할 값이며 괄호 자체는 입력하지 않습니다. 명령은 기본적으로 한 줄로 제시합니다. Bash에서 쓰는 역슬래시 줄바꿈은 PowerShell 문법이 아닙니다.

## 이 판에서 사용한 컴파일러 수정
예제를 빌드하면서 KITAQGB의 내부 로컬 레이블 충돌과, KITAQFC의 호출 전후 중간값·반환값 보존 문제를 발견했습니다. 기록된 검사는 이를 수정한 컴파일러로 수행했으며, GB 오브젝트 풀과 FC 함수·구조체 예제도 포함합니다. 이것이 모든 C 구문을 지원한다는 뜻은 아닙니다. 각 예제의 [검증 기록](verification.html)을 확인하세요.
