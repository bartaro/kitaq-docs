## 从这里开始
KITAQGB 最初是 Zachtronics 相关 NES C 编译器 **NORCAL 的一个分支**。在此基础上，项目针对 Game Boy 和 Game Boy Color 的处理器、内存、图像、音频及 ROM 分页机制进行了扩展，形成了一套 C 语言开发工具。我们保留原作者 Keith Holman 的版权声明，并感谢原项目的贡献。

NORCAL 的开发与 NES 版 HACK*MATCH 有关。背景资料可参阅原作者的 [NORCAL 介绍](https://keithholman.net/nes-compiler.html)和 [NES 版 HACK*MATCH 介绍](https://trashworldnews.com/hack-match/)。

## 怎样使用这套手册
这套手册沿用早期计算机手册的思路：先输入一个小程序，完成编译并看到运行结果，再逐步理解机器的工作方式。初学时不必先记住所有术语。

1. 开发 GB 程序，从第 1 卷的第一个程序开始；开发 FC 程序，从第 4 卷开始。
2. 通过第 2 卷或第 5 卷加入输入、图像和声音。
3. 用 KOKURA 或 KUROSAKI 观察运行过程，再用 SARAKURA 整理诊断结果。
4. 已经知道函数名称时，可直接使用卷内搜索或 API 字典。

语言语法、编译器内建函数、库函数和命令行操作是不同类型的参考条目。编译器分卷还附有 CPU 指令索引。GB 与 FC 中同名的函数，其参数和行为未必相同。

## 七卷的分工
| 分卷 | 输入 | 输出或用途 |
| --- | --- | --- |
| KITAQGB | C 源码和素材 | GB/CGB ROM、映射文件和构建信息 |
| KITAQGB 库 | 游戏代码中的调用 | 图像、音频、输入、通信和游戏辅助功能 |
| KOKURA | GB/CGB ROM | 运行、画面、音频、状态和观察记录 |
| KITAQFC | C 源码和 CHR 素材 | NES/FDS 输出及构建信息 |
| KITAQFC 库 | 游戏代码中的调用 | NES 图像、音频和外设功能 |
| KUROSAKI | NES/FDS 镜像 | 运行、记录和分析 |
| SARAKURA | 构建信息和诊断事件 | 报告、修复计划和复测计划 |

## 示例使用的字形
26 个大写字母、10 个数字、26 个小写字母和 30 个符号均来自作者提供的 [ascii.c](samples/assets/ascii.c)。没有另外设计或补入字形，原有 92 个字形均保持不变。可查看[转换对应表](verification/font_conversion.json)和[图块总览](verification/font_source_atlas.png)。空格使用空白图块。原文件没有反斜杠和竖线，它们会显示为空白。`gb_font.c` 和 `fc_font.c` 可显示全部已提供字形。

## 版本与验证范围
本手册以 **2026年9月14日的源码**为依据。参考清单记录了源码和可执行文件的哈希值。各项测试的输入、条件与验证范围请查阅验证记录。

构建成功只表示生成了 ROM；运行检查表示模拟器前进了指定帧数。像素对照、输入行为和音频检查分别记录。本手册不保证所有外设或真实主机的兼容性，日志中的警告也予以保留。

当前公开源码不包含 KOKURA-GUI、KUROSAKI-GUI 和 PLITA。请使用已经公开的核心、CLI 和集成 API。

## 准备工作目录
示例命令使用 **Windows PowerShell**。C 文件请保存为 UTF-8 文本。“当前目录”就是执行命令的位置。包含空格的路径需要加引号；必要时用 `& "路径"` 调用可执行文件。按照 [GitHub 目录布局说明](../GITHUB_SETUP.md)，把各仓库克隆到同一个父目录下，跨项目命令从该父目录执行。

请把 `game.c`、`game.gb` 和 `game.nes` 换成自己的文件名。`<ROM>` 这类尖括号内容表示占位参数，输入时不要保留尖括号。命令通常以单行给出。Bash 的反斜杠续行方式不适用于 PowerShell。

## 本版采用的编译器修复
构建示例时发现了 KITAQGB 内部局部标签重名问题，以及 KITAQFC 在函数调用前后保留中间值和返回值的问题。记录中的检查使用了修正后的编译器，包括 GB 对象池和 FC 函数、结构体示例。这并不等于支持所有 C 语言结构。具体情况请查看各示例的[验证记录](verification.html)。

## 阅读、打印与发布 HTML
打开下载目录中的 `index.html` 即可离线阅读。样式、搜索、示例和验证图片都使用本地文件，不依赖外部 CDN。请保持整个目录结构，不要只复制某一个 HTML 文件。打印按钮会使用隐藏侧栏的打印布局。

手册网站位于 `kitaq-docs` 仓库。GitHub 的仓库浏览界面通常显示 HTML 源码，GitHub Pages 才将其作为网页呈现。发布和源码布局请参阅仓库 README。各语言版共用同样的七卷、API 条目、示例程序和验证资料。源码摘录及实际工具输出保留原文，便于准确核对。
