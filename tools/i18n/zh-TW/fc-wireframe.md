`wire3d.c` 以暗色背景上的青色線條繪製自行製作的 3D 模型。它使用整數旋轉、倒數表透視投影、CPU 端像素緩衝區，以及兩個 CHR RAM 圖樣表。不含商業遊戲的程式碼、模型或圖像資料。原始碼由 DAISUKE OBA 以 MIT 授權條款提供。

引入 `wire3d.c` 之前，請從 64×48、96×64、128×96 選擇視口大小，並定義 `WIRE3D_FC_WIDTH` 和 `WIRE3D_FC_HEIGHT` **這兩個巨集**。預設為 64×48。視口位於 256×240 背景的中央。視口越大，使用的圖塊越多，線段也越長，因此請根據實際場景的效能測量結果選擇。

ROM 需要 **8 KiB 可寫入的 CHR RAM**，以及涵蓋 `$6800–$70BF` 的卡匣 PRG RAM。繪圖器獨占兩個圖樣表、名稱表 0、捲動設定和背景調色盤，並保留零頁 `$00–$0A`。請勿將這些區域用於其他用途，也不要在繪圖時改變它們的映射器對應。`--nes-chr-ram` 選用 RAM 而非 CHR ROM；它不能與透過 `--nes-chr` 或 `--chr-rom` 指定圖像檔的選項併用，CNROM 配置也不接受此選項。

繪圖器不可重入。初始化時會停用 NMI，完成設定後啟用背景。繪圖與上傳都在呼叫端的執行流程中進行；請勿同時執行其他 PPU 寫入程序，或會修改其工作記憶體的中斷處理程序。一次上傳可能跨越多個顯示影格。此實作不提供非同步遊戲迴圈或音訊更新排程器。

| 函式 | 用途與呼叫條件 |
|---|---|
| `Wire3DFC_Init()` | 清空兩個 CHR 圖樣表和 CPU 繪圖緩衝區，建立置中的圖塊地圖，設定暗底青線配色，並在 NMI 停用的情況下啟用背景。請在任何影格操作之前呼叫。 |
| `Wire3DFC_BeginFrame()` | 清除前一次繪圖所使用的 CPU 端圖塊。畫面上的影像會保留到 `EndFrame` 交換緩衝區為止。每次開始組成一張完整影像前呼叫一次。 |
| `Wire3DFC_DrawLine2D(ax,ay,bx,by)` | 在 CPU 緩衝區中繪製包含兩端點的線段。端點為 −512…511 範圍內的帶正負號座標。視口外的像素會被裁切；包圍盒完全位於視口外的線段則直接排除。範圍內的線段使用以 6502 暫存器為主的 Bresenham 迴圈繪製。 |
| `Wire3DFC_RotatePoint(x,y,z,rx,ry,rz)` | 依 Y、X、Z 軸順序旋轉並更新三個彼此獨立、可寫入的 `s16` 分量。一圈分為 32 個角度階段，超出後循環。各分量的初始值須在 −63…63 內。Q6 縮減採朝零截斷。只要任一分量指標為 NULL，就不執行任何修改。 |
| `Wire3DFC_ProjectPoint(x,y,z,sx,sy)` | 將相機座標中的點轉換為螢幕座標。X/Y 須在 −127…127 內，深度須在 32…255 內。成功時回傳 1，並寫入尚未裁切的帶正負號座標；座標無效或輸出指標為 NULL 時回傳 0，且不改動輸出。X 正方向朝右，Y 正方向朝上。 |
| `Wire3DFC_DrawLine3D(ax,ay,az,bx,by,bz)` | 投影兩個端點，再繪製螢幕上的線段。只要任一端點不符合投影範圍，就省略整條邊。不會計算邊與近裁切面或遠裁切面的交點。 |
| `Wire3DFC_DrawModel(vertices,count,edges,edge_count,x,y,z,rx,ry,rz)` | 對前 24 個以內的頂點各進行一次變換與投影，快取結果，再依索引繪製邊。每個頂點包含三個 `s8` 分量，每條邊包含兩個 `u8` 頂點索引。NULL 陣列、無效索引和被投影檢查排除的端點都會略過。請讓平移後的總和保持在 `s16` 範圍內。所有有效的邊都會繪製；此 API 不進行隱面消除。 |
| `Wire3DFC_EndFrame()` | 上傳待顯示影像或隱藏 CHR 緩衝區先前內容所使用的圖塊，也包含需要清除的圖塊。每次 VBlank 最多傳送 16 個圖塊，恢復捲動設定後，在新的 VBlank 顯示完整影像。此呼叫會等待直到完成。 |

`EndFrame` 執行後，`wire3d_uploaded_tiles` 表示已上傳的圖塊數，`wire3d_transfer_frames` 表示上傳批次數加上最後一次交換緩衝區的等待次數。後者**不是繪圖的總耗時**：變換、光柵化和 CPU 端狀態管理也需要時間。透視投影使用量化倒數表；在 128 像素寬視口的最近深度處，比例值會從 256 飽和限制為 255。

HTML 說明書的立方體範例示範頂點共用、旋轉、投影、12 條索引邊，以及完整影像的呈現。驗證影像顯示繞 Y 軸旋轉的立方體；12 條邊應全部相連，且不得殘留上一張影像的線條。
