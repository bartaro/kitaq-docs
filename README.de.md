## HTML-Handbücher

[Deutsch](https://bartaro.github.io/kitaq-docs/de/index.html)

Die sieben Bände enthalten einzelne API-Erklärungen und vollständige Beispielprogramme. Die deutsche Ausgabe beginnt unter `de/index.html`. Über das Sprachmenü jedes Bandes lässt sich eine andere Ausgabe wählen. Die Beispielbeschreibungen benennen das geprüfte Verhalten und die jeweiligen Bedingungen.

Quellcodeauszüge bleiben unverändert; Bildschirmaufnahmen aus dem Emulator stehen neben den Beispielerklärungen. Die HTML-Dateien unterstützen Offline-Lesen, Suche innerhalb eines Bandes, Kopieren von Code und Drucken.
