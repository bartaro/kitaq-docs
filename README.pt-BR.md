## Leitura offline e impressão

Abra index.html na pasta baixada para ler offline. Mantenha a pasta completa, incluindo imagens, exemplos e estilos. Cada volume permite pesquisar e copiar código pelos botões de cópia. O botão de impressão remove a coluna de navegação.
