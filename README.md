## Offline reading and printing

Open index.html from the downloaded folder to read offline. Keep the complete folder, including images, samples and styles. Search within each volume and use the Copy buttons for code. The Print button produces a page without the navigation column.

[Game development prompts](https://bartaro.github.io/kitaq-docs/en/loop-engineering.html)

## 日本語マニュアル

[目次から読む](https://bartaro.github.io/kitaq-docs/)

GB/CGB向け開発はKITAQGB、FC/NES向け開発はKITAQFCから始めてください。ライブラリの使い方は各ライブラリ編、実行・記録はKOKURA／KUROSAKI、診断はSARAKURAで説明しています。

フォルダー一式をダウンロードすると、`index.html`からオフラインでも読めます。各巻の検索、コードのコピーボタン、印刷機能も利用できます。
